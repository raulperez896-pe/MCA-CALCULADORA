# MCA CALCULADORA — Master Center Américas

## Archivos para GitHub Pages

Sube estos archivos a la raíz del repositorio:

- `index.html`
- `base_convenios_editable.csv`
- `logo-mca.png`
- `logo-bbva.jpg`

`README.md` es opcional.

## Importante

No cambies los nombres de los cuatro archivos anteriores, porque `index.html` los busca con esos nombres.

## Publicación

GitHub → Repository → Settings → Pages → Build and deployment:
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- Save

La página quedará en una dirección similar a:

`https://TUUSUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

## Actualizar la base

Edita `base_convenios_editable.csv` en Excel y guárdalo como CSV UTF-8. Vuelve a subirlo al mismo repositorio. No necesitas cambiar `index.html`.
