# MCA CALCULADORA V6

- El selector de Convenio usa únicamente la columna Convenio de Adicional Core.
- Se filtran registros válidos por N numérico para impedir que cargos, encabezados u otros campos aparezcan en Convenio.
- El lector CSV soporta correctamente saltos de línea dentro de celdas de tasas.
- La Provisión ya NO se ingresa manualmente.
- La Provisión se obtiene automáticamente de la fila seleccionada y se expresa en S/.
- Cálculo: Ingreso Neto × RCI − Provisión = Cuota Máxima RCI.
- La provisión NO se resta del ingreso neto.
- Mantiene las cinco opciones de seguro.
