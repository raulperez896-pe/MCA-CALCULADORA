# MCA CALCULADORA V45

Cambios:
- Se reemplaza Edad actual por Fecha de nacimiento.
- Se calcula automáticamente el plazo máximo según la Edad Máxima del perfil seleccionado.
- La fecha límite de vencimiento se fija a UN MES ANTES de la fecha en que el cliente cumple la Edad Máxima.
- El plazo máximo se expresa en meses desde la fecha de desembolso.
- Se muestra Plazo Máximo en el cuadro de Resultado de la simulación.
- Si el plazo solicitado supera el máximo, se muestra advertencia para reducirlo.
- Se conserva el motor de cronograma V43/V44 internamente, aunque su detalle esté oculto.
- Se conserva la base de convenios, accesos, tasas, provisiones, boletas, deudas y diseño responsive.
